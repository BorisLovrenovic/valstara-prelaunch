# Cookie and storage inventory

This site has two browser-storage entries. It sets no cookies.

| Name             | Kind                     | Purpose                                            |
| ---------------- | ------------------------ | -------------------------------------------------- |
| `valstara-theme` | Local storage            | Remembers your light or dark theme choice          |
| `cf.turnstile.u` | Cloudflare local storage | Helps secure a form when its Turnstile widget runs |

The theme preference is functional and does not identify you. Cloudflare Turnstile reads and writes `cf.turnstile.u` only when a protected form's widget runs. We rely on the Article 5(3) strictly-necessary exemption for security of the form you submit. The site does not use browser storage for analytics, advertising or referrals. Referral information is handled on the server. The site runs no device-fingerprinting API.

No non-essential information is stored on or accessed from your device, so there is no cookie banner. Three automated checks guard this: one rejects unapproved site-code cookie and storage use, one rejects site-run fingerprinting APIs, and one rejects unapproved third-party requests from pages. Rendered-page checks inspect every page's storage access, the completed Turnstile token on protected forms, and cookies.

Read the [privacy notice](/privacy) for how we use personal data.
