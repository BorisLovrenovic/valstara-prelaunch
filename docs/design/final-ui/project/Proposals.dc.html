P1 · One display size for the hero H1

Rule it would change: Section 4.2: six sizes only; H1 is 32/40 on desktop. Proposal: Adds 48/56 700 for the landing H1 at 1024+ only (phone and tablet stay 32/40). What it improves: The hero gains a clear first read at 1440 without a louder colour or a bigger visual; the scan path starts on the promise instead of the banner stack.
