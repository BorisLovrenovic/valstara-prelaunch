Token sheet

Every value an engineer measures resolves to one of these custom properties in valstara.css (section 4 names exactly as given). Tokens marked delta are new and are listed with their reason on the Change log board. Ratios are WCAG contrast against the surface named.

Colour · light (default)

The frame is neutral; provider colours appear only inside their own banner. Coral marks the one action, numerals, link underlines, coral pills and the focus ring, never body text.
