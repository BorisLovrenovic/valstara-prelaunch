Date: 2026-11-13. This record completes QA gate 7 finding **G7-1-T5**: run 1 sampled acceptance criteria for the feature specs that E11 and E11.5 touched instead of mapping all of them. It maps every acceptance-criterion checkbox and every item under "Edge cases and error states" in those specs to the code that implements it and the test that would fail if it broke.

**This map records gaps; it does not fix them.** Writing the missing tests, or changing a spec whose wording has drifted from a founder decision, is outside this finding. Each gap is listed once under [Gaps](#gaps), with its owning ticket where the plan makes that clear.

## Method

The edge-case sections are prose paragraphs, so each "condition → outcome" statement and each separate requirement sentence is one row. `README.md` has no edge-case section; its eleven cross-cutting bullets are the rows. Every spec's checkbox count was reconciled against its "AC" rows, and every edge-case sentence against its "Edge" rows; none is missing.

A row is `mapped` only where the cited test was opened and its assertions would fail if the behaviour broke. `partial` says what is missing. `manual/evidence` cites the recorded audit or drill. `not yet applicable` says why: either a later ticket owns the check by founder decision, or the item is an accepted risk or a pointer to another spec rather than a behaviour. Nothing was run for this record. Every one of the 256 distinct test-name citations was checked by string match against its cited file; one citation was corrected: the Turnstile expired and error tests in `signup.md` are one parameterised test, "a Turnstile ${turnstileMode} callback fails honestly without submitting".
